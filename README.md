# EX.No.2.1  CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING
## Date:

## AIM
To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE

Step 1: Create a new design
1. Open Autodesk Fusion 360.
2. Click File → New Design.
3. Click Create Sketch.
4. Select the XY plane.
Step 2: Draw the base rectangle
1. Click Rectangle → 2-Point Rectangle.
2. Draw a rectangle from the origin.
3. Press D to add dimensions.
4. Set the base dimensions to the overall dimensions shown in your drawing (approximately 100 mm length and 50 mm height; verify the drawing's exact values).
5. <img width="340" height="373" alt="Screenshot 2026-11-24 191900" src="https://github.com/user-attachments/assets/5ddbdd08-ef61-4d22-a109-a0006768d807" />

Step 3: Extrude the base
1. Click Finish Sketch.
2. Press E (Extrude).
3. Select the rectangle profile.
4. Enter the base width/depth.
5. Set the operation to New Body.
6. Click OK.
Your main rectangular base is ready.

<img width="248" height="306" alt="Screenshot 2026-11-24 191954" src="https://github.com/user-attachments/assets/0b80e83b-f2e0-4362-a404-28630521b345" />

Step 4: Sketch the circle on the front face
1. Rotate the model to the Front view using the ViewCube.
2. Select the front face of the base.
3. Click Create Sketch.
4. Click Circle → Center Diameter Circle.
5. Draw a circle near the lower-middle area of the front face.
6. Press D and enter 50 mm diameter (Ø50).
7. Position the circle as shown in the drawing.
Step 5: Extrude the cylinder
1. Click Finish Sketch.
2. Press E to open Extrude.
3. Select the circle.
4. Enter 20 mm extrusion distanc Choose Join if the cylinder is connected to the block.
6. Click OK.
Now the front cylindrical projection is ready.
<img width="337" height="376" alt="Screenshot 2026-11-24 192545" src="https://github.com/user-attachments/assets/45210a30-8b34-4aea-8166-c6af1bf54b61" />
Step 6: Create the upper rectangle
1. Click the top face of the main base.
2. Click Create Sketch.
3. Select Rectangle → 2-Point Rectangle.
4. Draw the upper block at the rear-left portion of the base.
5. Set the length and width according to the drawing.
Step 7: Extrude the upper block
1. Click Finish Sketch.
2. Press E.
3. Select the rectangular profile.
4. Enter 15 mm height (as indicated in the upper dimension).
5. Set the operation to Join.
6. Click OK.
The upper raised rectangular block is now complete
<img width="418" height="202" alt="Screenshot 2026-11-24 192610" src="https://github.com/user-attachments/assets/bcab5271-5350-4d85-a0ee-b5055fa0bd90" />

Step 8: Sketch the sloping profile
1. Rotate the model to its side view.
2. Select the side face of the upper raised block.
3. Click Create Sketch.
4. Click the Line tool (L).
5. Draw a triangular profile to remove the material and create the slope.
6. Set the inclined line to 45°, as shown in the drawing.
Step 9: Cut the slope
1. Click Finish Sketch.
2. Press E.
3. Select the triangular region.
4. Set the operation to Cut.
5. Set the cut distance to pass through the upper block.
6. Click OK.
The sloping surface is complete.
Part 5 – Create the small square boss
Step 10: Draw the square
1. Select the top face of the upper block.
2. Click Create Sketch.
3. Select Rectangle → 2-Point Rectangle.
4. Draw a small square on the top-left portion.
5. Set its dimensions to 15 mm × 15 mm, if those are the intended dimensions in the drawing.
6. Click Finish Sketch.
Step 11: Extrude the square
1. Press E (Extrude).
2. Select the square profile.
3. Enter the required height.
4. Select Join.
5. Click OK.

Part 6 – Create the top circular boss (Ø20)
<img width="328" height="357" alt="Screenshot 2026-11-24 192641" src="https://github.com/user-attachments/assets/ec2ac2d5-efd3-4d43-9d8c-8771be153ff0" />

Step 12: Draw the circle
1. Select the top face on the right side of the base block.
2. Click Create Sketch.
3. Select Circle → Center Diameter Circle.
4. Draw the circle.
5. Press D.
6. Enter 20 mm diameter (Ø20).
7. Place the circle at the position shown in the drawing.
Step 13: Extrude the circular boss
1. Click Finish Sketch.
2. Press E.
3. Select the circular profile.
4. Enter 10 mm height.
5. Set the operation to Join.
6. Click OK.
Step 14: Check the model
1. Rotate the model using the ViewCube.
2. Check the Front, Top and Right views.
3. Verify the 100 mm base length and 50 mm overall base height.
4. Check the Ø50 front cylinder.
5. Check the 45° inclined surface.
6. Check the 15 mm square boss and Ø20 circular boss.
7. Click File → Save and save your model.
